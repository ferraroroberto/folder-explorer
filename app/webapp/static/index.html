          Size and On disk

          Size is a file's full length: what the cloud stores and what you would download.

          On disk is the space it takes on this PC. An online-only file () takes nothing until you open it: a 567 KB document shows Size 567 KB and On disk 0 B.

          The scan reads folder listings only. It never opens a file, so it never downloads one.

          How scanning works

          A scan walks each root in the background and saves an index on this PC, so the app opens instantly with the last result.

          It reads names, sizes, dates and cloud state from the folder listing, one folder at a time. File contents are never read.

          A rescan replaces the index when it finishes; until then you keep browsing the previous one. Junctions and links are counted, never followed, so nothing is counted twice.

          Scans run from the Rescan button, from the schedule in Settings, or from the command line (python -m app.cli scan). Only one runs at a time.
