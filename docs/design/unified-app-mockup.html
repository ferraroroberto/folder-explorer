                    Outlook macro

                    An Archive button on Outlook's ribbon files the selected or open mail. It starts folder-explorer's windowless archive entry with the mail's ID and returns straight away, so Outlook never waits on it.

                    The same Archive sheet then opens in the app. If the app isn't open in a browser, a small window shows the same suggestions instead.

                    Set up once per PC: import the template below, set FOLDER_EXPLORER_HOME to the checkout folder, and add the macro to the ribbon.

                    The new Outlook for Windows runs neither macros nor COM, so archiving needs Outlook (classic).

                    VBA · ArchiveCurrentItem
                    Sub ArchiveCurrentItem()
    Dim it As Object, home As String, cmd As String
    If TypeName(Application.ActiveWindow) = "Inspector" Then
        Set it = Application.ActiveInspector.CurrentItem
    ElseIf Application.ActiveExplorer.Selection.Count > 0 Then
        Set it = Application.ActiveExplorer.Selection.Item(1)
    Else
        Exit Sub
    End If
    home = Environ$("FOLDER_EXPLORER_HOME")
    cmd = """" & home & "\.venv\Scripts\pythonw.exe"" -m app.outlook archive" _
        & " --entry-id " & it.EntryID & " --store-id " & it.Parent.StoreID
    CreateObject("WScript.Shell").Run cmd, 0, False
End Sub

                    Size and On disk

                    Size is a file's full length: what the cloud stores and what you would download.

                    On disk is the space it takes on this PC. An online-only file () takes nothing until you open it.

                    How scanning works

                    One walk per root reads names, sizes, dates and cloud state from the folder listings. It feeds three things at once: the disk sizes, the folder index, and the list of .msg files that are new or changed.

                    The walk never opens a file. Junctions and links are counted, never followed. Excluded folders are skipped by all three.

                    Scans run nightly from the app-launcher job, from Rescan here, or from python -m app.cli scan.

                    What the email stage reads

                    Only .msg files inside the email folders, and only the ones that are new or changed since the last run. An unchanged file is never touched.

                    Reading an online-only file downloads it from OneDrive. Each run stops downloading at the budget and picks up the rest next run. Downloaded files stay on disk until OneDrive frees them.

                    Files are opened read-only. Nothing changes a file, its attributes or its pin state. A file that fails isn't retried until it changes.
